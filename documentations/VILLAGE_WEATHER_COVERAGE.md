## 🎯 Testing Village Coverage

Want to test if a specific village works? Here's how:

### Quick Test Script

```python
import httpx
import asyncio

async def test_village(lat, lon, village_name):
    async with httpx.AsyncClient() as client:
        response = await client.get(
            "https://api.open-meteo.com/v1/forecast",
            params={
                "latitude": lat,
                "longitude": lon,
                "current": "temperature_2m"
            }
        )
        if response.status_code == 200:
            data = response.json()
            temp = data["current"]["temperature_2m"]
            print(f"✅ {village_name}: {temp}°C")
        else:
            print(f"❌ {village_name}: Error")

# Test any village
asyncio.run(test_village(14.9167, 75.3833, "Hirekerur"))

# Test Vijayapura village
asyncio.run(test_village(16.7500, 75.8000, "Babaleshwar, Vijayapura"))
```
